# Handmade Store 🎨

منصة متكاملة لبيع المنتجات اليدوية (Handmade Products) مع دعم متعدد البائعين وميزات ذكاء اصطناعي.

## 🚀 الميزات

- 🔐 نظام تسجيل دخول (عميل / بائع / أدمن)
- 🛍️ عرض المنتجات مع بحث وتصنيفات
- 🛒 سلة مشتريات وإتمام الطلب
- 📊 لوحة تحكم للأدمن
- 🏪 نظام متعدد البائعين (Multi-Vendor)
- 🤖 بحث ذكي وتوصيات AI

## 🛠️ التقنيات

- Frontend: React, Tailwind CSS
- Backend: Node.js, Express
- Database: PostgreSQL (Supabase)
- Auth: JWT
- Hosting: Vercel (Frontend) + Render (Backend)
